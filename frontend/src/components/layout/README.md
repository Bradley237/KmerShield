# components/layout/

### What Belongs Here
- Global navigation and layout elements:
  - `Header.tsx` (responsive navigation, mobile drawer, anchor smooth-scroll)
  - `Footer.tsx` (legal links, disclaimer, copyright)
  - `Logo.tsx` (SVG shield and wordmark)
  - `LanguageSwitch.tsx` (FR | EN toggle syncing `<html lang>`)
  - `ThemeToggle.tsx` (Light / Dark / Auto cycle)

### What Does NOT Belong Here
- Page-specific body sections.
- Form controls (use `components/ui/`).
