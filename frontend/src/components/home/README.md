# components/home/

### What Belongs Here
- Home landing page sections matching Stitch designs:
  - `Hero.tsx`: Headline, reassurance row, layered composition card, fictitious sample chip.
  - `ProblemSection.tsx`: 3 informal transaction risk cards.
  - `HowItWorks.tsx`: 3 steps with dotted connector line.
  - `RiskLevels.tsx`: Visual overview of risk appreciation levels.
  - `Limits.tsx`: Persistent dark section (`[data-surface="dark"]`) with lists and commitments.
  - `Faq.tsx`: Accordion with first item open by default.
  - `FinalCta.tsx`: Indigo band action banner.

### What Does NOT Belong Here
- Generic reusable primitives (use `components/ui/`).
- Auth forms or modals.
