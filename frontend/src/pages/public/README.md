# pages/public/

### What Belongs Here
- Public marketing and informative pages accessible without authentication.
- `Home.tsx`, `NotFound.tsx`, `Privacy.tsx`, `Terms.tsx`, `Contact.tsx`.
- All user-facing strings must reference `locales/` keys.

### What Does NOT Belong Here
- Authentication forms (use `pages/auth/`).
- Raw atomic buttons, inputs, or badges (use `components/ui/`).
- Direct fetch calls (use `services/`).
