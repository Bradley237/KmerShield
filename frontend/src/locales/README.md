# locales/

### What Belongs Here
- Bilingual translation dictionaries: `fr.json` (French, default) and `en.json` (English).
- Nested keys organized logically by domain: `brand`, `nav`, `home`, `auth`, `risk`, `common`, `notFound`, `footer`.
- Adheres strictly to vocabulary guidelines: "évaluation du risque", "conseils", "autoévaluation". Never "protection garantie" or "100% sûr".

### What Does NOT Belong Here
- Code logic, JavaScript/TypeScript objects, or functions.
